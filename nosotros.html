Sobre Al Día

Al Día es una plataforma web de noticias desarrollada como proyecto académico del módulo de Desarrollo de Front-end del Politécnico Grancolombiano. Su propósito es ofrecer a los usuarios un espacio digital para consultar noticias educativas, tecnológicas, turísticas y comerciales.

El proyecto fue construido con HTML5, CSS3 y JavaScript vanilla, aplicando buenas prácticas de desarrollo web como separación de responsabilidades, renderizado dinámico desde JSON y persistencia de favoritos mediante localStorage.
